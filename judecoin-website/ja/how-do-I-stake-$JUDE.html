$JUDE のステーキング方法

JUDE のステーキングは Judecoin の Service Node を通じて行われます。

Judecoin Service Node は、Judecoin ネットワークの基盤を支えます。報酬を受けるノードによって、ネットワーク機能、拡張性、分散型技術スタックを実現します。

Judecoin Service Node を運用するには、運用者は必要ステーク額である 23,600 JUDE をロックします。ステーク取引がネットワークへ送信され、登録プロセスが承認されると、Service Node は有効化され、ネットワークへの貢献を開始します。

サービス提供の対価として、条件を満たす Judecoin Service Node 運用者は、現在のコンセンサスと報酬分配ルールに従ってブロック報酬の一部を受け取ります。

ネットワークに承認されると、Service Node は報酬を受け取る資格を得ます。

Judecoin Service Node の運用は、報酬を得ながら分散型インフラを支援し、Judecoin のプライバシーネットワークに参加するための非常に直接的な方法です。

共有 Service Node

複数の参加者は、小口のステークを組み合わせて 23,600 JUDE の Service Node ステーキング要件を満たし、共有 Service Node に参加できます。

共有ステーキング参加

複数の参加者は、小口のステークを組み合わせて 23,600 JUDE の Service Node ステーキング要件を満たし、共有 Service Node に参加できます。

報酬は、各参加者のステーク貢献額と適用されるネットワークルールに従って、参加者へ比例配分されます。

フルサーバーを運用せずに参加できるよう設計されています。

サーバー運用なしでネットワークを支援

共有 Service Node により、ユーザーは自分でフルサーバーを運用しなくても JUDE ステーキングに参加しやすくなります。

ユーザーは、自分の貢献に応じた報酬を受け取りながら、Judecoin ネットワークのセキュリティと運用に貢献できます。

共有 Service Node に参加するユーザー向けに設計されています。

ステーキングオプション

Judecoin ステーキングは、参加をできるだけ迅速かつ簡単にするよう設計されています。

共有Service Nodeに参加

自分でサーバーを管理したくないユーザーは、共有 Service Node を通じて参加できます。

ステーキング取引を送信する前に、ユーザーは最新の Service Node ドキュメントに従い、ウォレット、Service Node 情報、ステーキング内容が正しいことを確認してください。

完全なService Nodeを運用する

自分のインフラを運用したいユーザーは、フル Judecoin Service Node を実行できます。

この方法には、適切なサーバー環境、最新の Service Node ソフトウェア、同期済み daemon、ウォレット登録、定期的なステータス確認、鍵のバックアップが必要です。

ステーキング前に

ステーキングに参加する前に、ユーザーはステーキング要件、ウォレットバージョン、Service Node 登録情報、バックアップ要件を確認する必要があります。

自分の Judecoin Service Node を運用する

自分の Judecoin Service Node を運用したいユーザーは、適切なサーバー環境を準備し、最新の Judecoin Service Node ソフトウェアを実行し、ノードをオンラインに保ち、Service Node 登録プロセスを完了する必要があります。

一般的な Judecoin Service Node のセットアップには次のものが必要です。

Service Node セットアップ要件

  • 対応する Linux サーバー環境
  • 十分なストレージ、メモリ、ネットワーク接続性、月間通信量
  • 開放され、到達可能な Service Node ポート
  • 最新の Judecoin Service Node バイナリ
  • 完全に同期された Judecoin デーモン
  • 必要なステーキング額を保有する Judecoin ウォレット
  • ウォレットからの Service Node 登録
  • 定期的な状態確認
  • ウォレットキーと Service Node キーのバックアップ
