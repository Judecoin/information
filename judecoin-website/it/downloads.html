CLI Wallet, GUI Wallet, and Palm Wallet are the primary ways to access Judecoin software across desktop and mobile platforms.

CLI Wallet

An open-source command line interface wallet developed by the Judecoin community. It is best suited for developers, intermediate users, and advanced users who want total control over their Judecoin node, funds, analysis tools, HTTP RPC, and 0MQ interface support.

GUI Wallet

The GUI wallet provides a clean user interface for storing, sending, receiving, and managing Judecoin and supported digital assets. It is especially useful for people who want fast everyday wallet access with advanced features available when needed.

The wallet page highlights open-source, non-custodial control and practical everyday features.

  • Completely open source

    Reap the benefits of security, power, and stability that only a fully open-source codebase can offer.

  • Non-custodial

    Judecoin Wallet keeps all private keys in your hands. You control the money inside it.

  • Multi-currency support

    Send, receive, and store Judecoin, Bitcoin, Ethereum, Cardano, Ripple, Dogecoin, Solana, Litecoin, Avalanche, Binance Coin, Polkadot, Tron and more.

  • Node options

    Auto connect to Judecoin nodes for a seamless experience, or choose your own.

  • Backup capabilities

    Custom backup capabilities help you safely and securely restore all wallets in two easy steps.

  • Smart sync

    Sync to the blockchain when it is convenient for you and minimize wait times before using your coins.

  • Address contacts

    Save multiple cryptocurrency addresses under one contact and assign an emoji.

  • Atomic swaps

    Judecoin supports decentralized atomic swaps of cryptocurrencies such as Bitcoin and Ethereum.

  • More to come

    More wallet capabilities and ecosystem updates may be added over time.
