Wie stake ich $JUDE?

JUDE-Staking erfolgt über Judecoin Service Nodes.

Judecoin Service Nodes leisten grundlegende Unterstützung für das Judecoin-Netzwerk. Sie werden durch incentivierte Nodes betrieben und ermöglichen Netzwerkfunktionen, Skalierbarkeit und einen dezentralisierten Technologie-Stack.

Um einen Judecoin Service Node zu betreiben, sperren Betreiber den erforderlichen Staking-Betrag von 23.600 JUDE. Die Stake-Transaktion wird an das Netzwerk übermittelt, und nachdem der Registrierungsprozess akzeptiert wurde, wird der Service Node aktiv und beginnt, zum Netzwerk beizutragen.

Als Gegenleistung für ihre Dienste erhalten berechtigte Judecoin-Service-Node-Betreiber gemäß den aktuellen Konsens- und Reward-Verteilungsregeln einen Anteil der Blockbelohnungen.

Service-Node-Staking

Rewards erhalten

Ein Judecoin Service Node wird im Netzwerk aktiv, wenn sein Eigentümer den erforderlichen JUDE-Betrag stakt und den Service-Node-Registrierungsprozess abschließt.

Sobald der Service Node vom Netzwerk akzeptiert wurde, ist er berechtigt, Rewards zu erhalten.

Der Betrieb eines Judecoin Service Nodes ist eine sehr gute Möglichkeit, am Judecoin-Privacy-Netzwerk teilzunehmen, Rewards zu verdienen und seine dezentrale Infrastruktur zu unterstützen.

Shared Service Nodes

Mehrere Teilnehmer können in einen Shared Service Node staken, indem sie kleinere Stake-Beiträge zusammenlegen, um die Staking-Anforderung von 23.600 JUDE für einen Service Node zu erfüllen.

Gemeinsame Staking-Beteiligung

Mehrere Teilnehmer können in einen Shared Service Node staken, indem sie kleinere Stake-Beiträge zusammenlegen, um die Staking-Anforderung von 23.600 JUDE für einen Service Node zu erfüllen.

Rewards werden im Verhältnis zum Stake-Beitrag jedes Teilnehmers und gemäß den geltenden Netzwerkregeln verteilt.

Entwickelt für Beteiligung ohne Betrieb eines vollständigen Servers.

Netzwerkunterstützung ohne Serverbetrieb

Shared Service Nodes erleichtern Nutzern die Teilnahme am JUDE-Staking, ohne selbst einen vollständigen Server zu betreiben.

Nutzer können zur Sicherheit und zum Betrieb des Judecoin-Netzwerks beitragen und dabei Rewards auf Grundlage ihres Beitrags erhalten.

Entwickelt für Nutzer, die einem Shared Service Node beitreten.

Staking-Optionen

Judecoin-Staking ist darauf ausgelegt, Beteiligung so schnell und einfach wie möglich zu machen.

Einem Shared Service Node beitreten

Nutzer, die keinen eigenen Server verwalten möchten, können über einen Shared Service Node teilnehmen.

Vor dem Einreichen einer Staking-Transaktion sollten Nutzer die neueste Service-Node-Dokumentation befolgen und sicherstellen, dass Wallet, Service-Node-Informationen und Staking-Details korrekt sind.

Einen vollständigen Service Node betreiben

Nutzer, die ihre eigene Infrastruktur betreiben möchten, können einen vollständigen Judecoin Service Node ausführen.

Dieser Weg erfordert eine geeignete Serverumgebung, die neueste Service-Node-Software, einen synchronisierten Daemon, Wallet-Registrierung, regelmäßige Statusprüfungen und Schlüssel-Backups.

Vor dem Staking

Vor der Teilnahme am Staking sollten Nutzer die Staking-Anforderungen, die Wallet-Version, die Service-Node-Registrierungsinformationen und die Backup-Anforderungen prüfen.

Nutzer sollten prüfen:

erforderlicher Staking-Betrag
für das Staking verwendete Wallet-Version
Service-Node-Registrierungsstatus
vom Betreiber bereitgestellte öffentliche Service-Node-Informationen, wenn man einem Shared Service Node beitritt
erwartete Sperrbedingungen
Regeln zur Reward-Verteilung
Backup-Anforderungen für Wallet-Schlüssel und Service-Node-Schlüssel
Wiederherstellungsanforderungen vor dem Verschieben von Mitteln, Wechseln von Wallets oder Migrieren von Serverumgebungen

Nachdem ein Stake vom Netzwerk akzeptiert wurde, werden Rewards gemäß den Netzwerkregeln, der Service-Node-Berechtigung und dem Stake-Beitrag des Teilnehmers verteilt.

Den eigenen Judecoin Service Node betreiben

Nutzer, die ihren eigenen Judecoin Service Node betreiben möchten, sollten eine geeignete Serverumgebung vorbereiten, die neueste Judecoin-Service-Node-Software ausführen, den Node online halten und den Service-Node-Registrierungsprozess abschließen.

Anforderungen für die Service-Node-Einrichtung

  • unterstützte Linux-Serverumgebung
  • ausreichend Speicherplatz, Arbeitsspeicher, Netzwerkverbindung und monatliches Datenvolumen
  • offene und erreichbare Service-Node-Ports
  • neueste Judecoin-Service-Node-Binaries
  • vollständig synchronisierter Judecoin-Daemon
  • Judecoin Wallet mit dem erforderlichen Staking-Betrag
  • Service-Node-Registrierung aus dem Wallet
  • regelmäßige Statusprüfungen
  • Backups von Wallet-Schlüssel und Service-Node-Schlüssel
